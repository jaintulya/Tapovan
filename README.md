# Tapovan Vatsalyadham School (English Medium)

Official website for **Tapovan Vatsalyadham School**, Gandhinagar, Gujarat. Managed by **Jivan Jagruti Trust** and affiliated with **CBSE** (Affiliation No. 430592 • School Code 11722).

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_GOOGLE_SHEET_URL=your_google_apps_script_webhook_url
```
